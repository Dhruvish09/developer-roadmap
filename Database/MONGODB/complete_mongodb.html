    ✅ MongoDB Complete Topics With Examples (Cheat Sheet)¶

    1. Basic Database & Collection Commands¶

    Create / Switch Database¶

    use mydb

    Show Databases¶

    show dbs

    Drop Database¶

    db.dropDatabase()

    Show Collections¶

    show collections

    Create Collection¶

    db.createCollection("students")

    Drop Collection¶

    db.students.drop()

    2. Insert Operations¶

    Insert One¶

    db.students.insertOne({
  name: "Rahul", age: 22, city: "Mumbai"
})

    Insert Many¶

    db.students.insertMany([
  { name: "Amit", age: 23 },
  { name: "Sneha", age: 21 }
])

    3. Find / Select Queries¶

    Find All¶

    db.students.find()

    Pretty Print¶

    db.students.find().pretty()

    Find With Fields¶

    db.students.find({ city: "Mumbai" })

    Find With Selected Columns¶

    db.students.find(
  { city: "Mumbai" },
  { name: 1, age: 1, _id: 0 }
)

    4. Query Operators¶

    Comparison Operators¶

    Operator Meaning Example
    $gt greater than age > 20
    $lt less than age < 25
    $gte ≥ age >= 18
    $lte ≤ age <= 30
    $ne not equal age != 25
    $in in list [1,2,3]
    $nin not in list [1,2,3]

    Example:

    db.students.find({ age: { $gte: 18, $lte: 25 } })

    5. Logical Operators¶

    AND Condition¶

    db.students.find({
  age: { $gt: 20 },
  city: "Delhi"
})

    OR Condition¶

    db.students.find({
  $or: [
    { city: "Delhi" },
    { city: "Mumbai" }
  ]
})

    NOT Operator¶

    db.students.find({
  age: { $not: { $gt: 25 } }
})

    6. Update Operations¶

    Update One¶

    db.students.updateOne(
  { name: "Rahul" },
  { $set: { city: "Pune" } }
)

    Update Many¶

    db.students.updateMany(
  { city: "Mumbai" },
  { $set: { verified: true } }
)

    Increment Value¶

    db.students.updateOne(
  { name: "Rahul" },
  { $inc: { age: 1 } }
)

    7. Delete Operations¶

    Delete One¶

    db.students.deleteOne({ name: "Rahul" })

    Delete Many¶

    db.students.deleteMany({ city: "Delhi" })

    8. Sort, Limit, Skip¶

    Sort¶

    db.students.find().sort({ age: 1 })   // 1 = Asc, -1 = Desc

    Limit¶

    db.students.find().limit(5)

    Skip¶

    db.students.find().skip(10)

    Pagination¶

    db.students.find().skip(10).limit(5)

    9. Indexing¶

    Create Index¶

    db.students.createIndex({ name: 1 })

    Unique Index¶

    db.students.createIndex({ email: 1 }, { unique: true })

    Show Indexes¶

    db.students.getIndexes()

    Drop Index¶

    db.students.dropIndex("name_1")

    10. Aggregation Framework (MOST IMPORTANT)¶

    Basic Aggregation¶

    db.students.aggregate([
  { $match: { city: "Mumbai" } },
  { $group: { _id: "$city", total: { $sum: 1 } } }
])

    Pipeline Structure¶

    Stage Description
    $match Filter data
    $group Group and aggregate
    $sort Sort results
    $limit Limit records
    $project Select fields
    $lookup Join collections
    $unwind Flatten arrays

    11. Group By (Equivalent of SQL GROUP BY)¶

    Total Students Per City¶

    db.students.aggregate([
  { $group: { _id: "$city", totalStudents: { $sum: 1 } } },
  { $sort: { totalStudents: -1 } }
])

    12. MongoDB Join (lookup)¶

    students + marks join¶

    db.students.aggregate([
  {
    $lookup: {
      from: "marks",
      localField: "student_id",
      foreignField: "student_id",
      as: "result"
    }
  }
])

    13. Projection (Select specific columns)¶

    db.students.find(
  {},
  { _id: 0, name: 1, city: 1 }
)

    14. Text Search¶

    Create Text Index¶

    db.products.createIndex({ name: "text", description: "text" })

    Search¶

    db.products.find({ $text: { $search: "mobile fast" } })

    15. Array Operators¶

    Find records where array contains value¶

    db.courses.find({ tags: "python" })

    Add value to array¶

    db.courses.updateOne(
  { name: "Backend" },
  { $push: { tags: "fastapi" } }
)

    Remove array value¶

    db.courses.updateOne(
  { name: "Backend" },
  { $pull: { tags: "django" } }
)

    16. $unwind (Expand array into multiple documents)¶

    db.orders.aggregate([
  { $unwind: "$items" }
])

    17. Distinct Values¶

    db.students.distinct("city")

    18. Counting¶

    Count documents¶

    db.students.countDocuments({ city: "Delhi" })

    19. Backup & Restore¶

    Backup¶

    mongodump --db=mydb

    Restore¶

    mongorestore --db=mydb dump/mydb

    20. ObjectId Operations¶

    Find by ObjectId¶

    db.students.find({ _id: ObjectId("65d10f3ca525d246df1257cd") })

    21. Replace Document¶

    db.students.replaceOne(
  { name: "Amit" },
  { name: "Amit", age: 25, city: "Delhi" }
)

    22. Upsert (Update + Insert)¶

    db.students.updateOne(
  { name: "John" },
  { $set: { age: 24 } },
  { upsert: true }
)

    23. Renaming Fields¶

    db.students.updateMany(
  {},
  { $rename: { "city": "location" } }
)

    24. Drop Field¶

    db.students.updateMany(
  {},
  { $unset: { age: 1 } }
)

    25. Creating & Using Views¶

    Create View¶

    db.createView(
  "mumbai_students",
  "students",
  [{ $match: { city: "Mumbai" } }]
)

    26. Bulk Write¶

    db.students.bulkWrite([
  { insertOne: { document: { name: "A", age: 20 } } },
  { updateOne: { filter: { name: "A" }, update: { $set: { age: 21 } } } },
  { deleteOne: { filter: { name: "A" } } }
])

    27. Transactions (MongoDB Atlas / Replica Set)¶

    session = db.getMongo().startSession()
session.startTransaction()

students = session.getDatabase("mydb").students

students.updateOne({ name: "A" }, { $set: { balance: 100 } })
students.updateOne({ name: "B" }, { $set: { balance: 200 } })

session.commitTransaction()
session.endSession()

    28. Schema Validation¶

    db.createCollection("employees", {
  validator: {
    $jsonSchema: {
      bsonType: "object",
      required: ["name", "age"],
      properties: {
        name: { bsonType: "string" },
        age: { bsonType: "int", minimum: 18 }
      }
    }
  }
})

    29. Change Streams (Real-time data watch)¶

    db.students.watch()

    30. TTL Index (Auto delete data)¶

    Auto delete logs after 2 days¶

    db.logs.createIndex(
  { createdAt: 1 },
  { expireAfterSeconds: 172800 }
)
