## 🔐 What is IAM?

**IAM (Identity and Access Management)** controls **who can access what** in a system.

---

## 🧩 IAM = 3 Simple Questions

1️⃣ **Who are you?** → *Identity*
2️⃣ **Can you log in?** → *Authentication*
3️⃣ **What can you do?** → *Authorization*

---

## 👤 Main IAM Parts (Very Easy)

* **User** → A person or app (example: you)
* **Group** → Collection of users (example: Dev team)
* **Policy** → Rules (what is allowed / denied)
* **Role** → Temporary permission (used by apps/services)

---

## 🧠 One-Line Example

> User logs in → IAM checks policy → allows or denies action
