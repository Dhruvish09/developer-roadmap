## ✅ **Core Tech Stack**

### 🔹 **Programming Language**

* **Python**: Data structures, OOP, decorators, generators, type hints, exception handling, file I/O

### 🔹 **Backend Frameworks**

* **FastAPI**: Request/response lifecycle, async support, dependency injection, Pydantic models, JWT auth
* **Flask**: Blueprints, middleware, request/response handling, RESTful API design
* **Django (Basic to Intermediate)**: ORM, views, templates, authentication

### 🔹 **Databases**

* **MongoDB**: NoSQL concepts, schema design, indexing, aggregation
* **MySQL**: Joins, indexing, normalization, query optimization, stored procedures
* **Redis**: Caching, pub/sub, Celery broker

### 🔹 **Cloud & Serverless**

* **AWS Lambda**: Stateless functions, IAM roles, deployment
* **AWS S3**: File storage, permissions, lifecycle rules

### 🔹 **Asynchronous Processing & Queues**

* **Celery**: Task queues, retry logic, scheduling, worker setup
* **RabbitMQ / Redis as broker**: Know basic concepts even if using Redis

---

## 🚀 **Advanced Tools**

### 🔹 **LLM & AI Ecosystem**

* **OpenAI / Anthropic / Gemini APIs**: API design, limitations, pricing, streaming
* **LangChain**: Agents, tools, memory, chaining, prompt templates
* **LangGraph**: Node-based LLM workflow orchestration, conditional flow, persistent agent state
* **Pinecone**: Vector database usage, upserts, similarity search, namespace handling

### 🔹 **Web Crawling & Content Extraction**

* **Playwright**: Browser automation, scraping, headless mode
* **BeautifulSoup**: HTML parsing and DOM traversal
* **Crawler4AI (custom)**: Know your own architecture, when and how it scrapes, integrates with LLMs

---

## 📈 **DevOps**

### 🔹 **Testing & CI/CD**

* **Pytest**: Fixtures, mocks, assertions, coverage
* **Nose**: Basic understanding
* **Locust**: Load testing basics
* **Jenkins**: Pipelines, CI/CD basics

### 🔹 **Docker & Deployment**

* **Docker**: Dockerfiles, volumes, environment variables, image layers
* **Docker Compose**: Multi-container setups, networks, service linking

### 🔹 **Monitoring & Observability**

* **Prometheus**: Metrics collection and alert rules
* **Grafana**: Dashboard creation, alerting
* **Loki + Promtail**: Log aggregation and querying

---

## 🔐 **Security Concepts**

* **JWT (JSON Web Tokens)**: Auth flow, token expiry, validation
* **CSRF Protection**: How it works and how to implement
* **Cryptography in Python**: Encryption/decryption basics (use of `cryptography` or `pycrypto`)

---

## 🧪 **Frontend**

* **HTML, CSS, Bootstrap**: Form handling, responsive design basics
* **ReactJS (team)**: Understand props, state, API integration – not in-depth but enough to collaborate

---

## ✉️ **Notifications & Messaging**

* **SMTP / SES**: Sending HTML emails, auth config
* **FCM (Firebase Cloud Messaging)**: For push notifications (optional unless you're applying for mobile-integrated systems)
